# Spike — Scout (Tier 1)

Research only. Use for "how does X work" or "where is Y handled".

## Sequence

1. Triage. If the request is to write code, stop and route to quick-fix or
   feature-factory.
2. Route to a technology expert for the domain. The expert reads the library
   pack for that technology.
3. Return the findings verbatim. No code changed.

## Hard rules

- No code is written.
- Do not propose solutions in your own voice.
