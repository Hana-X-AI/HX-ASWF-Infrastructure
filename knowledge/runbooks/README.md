# Runbooks

Operational procedures. Each runbook is one procedure, written to be followed by
an agent or a human without prior context.

This directory fills during M2 and M3. The first runbook is the activation
procedure for a parked product-line agent (see `GOVERNANCE.md`):

1. Re-ground the knowledge pack for that technology.
2. Validate (Tessa).
3. Add the agent to the active roster and commit the change.
