# Precedents

Validated patterns and libraries. What to reuse, what to avoid.

This directory fills during M3 as runs produce evidence. Each entry states what
was validated, how, and where the evidence lives.

Known precedents at skeleton time:

- **Grounding beats generalists.** A technology-grounded agent outperforms a
  generalist at that technology's work. Source: owner's Ollama install case.
- **Patterns to adopt from jcode** (not the tool): semantic agent memory, swarm
  collaboration with conflict detection, structure-aware grep.
