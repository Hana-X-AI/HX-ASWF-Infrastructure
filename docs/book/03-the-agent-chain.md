# 03 — The agent chain

The roster is two-class (KDD-024).

- **Technology experts** do the work. One per technology, grounded on that
  technology's source. They live in the library and are listed in `roster.yaml`.
- **Cross-cutting roles** hold the process. Coordinator (Xavier) routes,
  validator (Tessa) checks independently, reviewers audit, doc-writer documents.

A run binds a technology expert to a role. Reviewers stay cross-cutting, never
per-technology, so the fleet stays linear.

Full chain detail lands with M3.
