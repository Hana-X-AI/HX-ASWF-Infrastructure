# 00 — Introduction

The Agentic Software Factory (ASWF) is a machine that takes an input and
produces a product. The first product is the factory itself.

This repo is the machine. It carries its own manifest, generates its own rules
file, and enforces its own path guard. The git history shows the machine
building itself.

The chapters that follow explain the shape: the pipeline, the agents, the path
enforcement, the adapters, the profiles, and the decisions behind each.
