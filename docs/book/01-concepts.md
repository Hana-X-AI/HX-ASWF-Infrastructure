# 01 — Concepts

Four concepts shape the factory.

1. **Knowledge is foundational.** Knowledge is infrastructure: it lives in
   source control, travels with every agent, and improves over time.
2. **Agents + code beats agents alone.** Agents propose; code disposes.
3. **Governance by consequence.** Risk scales with impact, not effort. Ceremony
   is concentrated where it matters.
4. **No actor validates their own work.** Implementers verify, validators check
   independently, decision-makers accept or reject.
