# Per-agent evaluation cases

Each agent has one standard to be measured against. The cases land in M3.

## How evals gate agent changes

1. Each agent's prompt change is paired with its eval cases.
2. A change that regresses an eval does not merge.
3. The eval standard is the same one Tessa uses to judge the agent's output.

The directory is empty in M2 by design. It fills as agents are activated.
