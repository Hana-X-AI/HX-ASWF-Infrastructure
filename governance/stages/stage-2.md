# Stage 2 — Cross-cutting change

Applies when a change touches multiple layers, changes schema, or adds an API
contract.

## Rules

Everything in Stage 1, plus:

1. A ratified technical brief before build.
2. A human checkpoint after the brief.
3. An independent review (Tessa) before merge.
4. The API contract is published and consumed verbatim, not re-invented.

## Advancement

Advances to Stage 3 when the change ships to a user or needs a release.
